# NotePath: working brief

Read this first in every session. Keep it short and current: update it in the same commit as any change it describes.

## What NotePath is
A desktop notes console (Electron) for every kind of note a person would reach for a notepad for: quick lines, lists and checklists, meeting notes, study notes, photos, video, code and music. It is **the note-taking system of Inquire, cloned into its own app** (Inquire: `~/Documents/codex-desktop`, repo `InquiringOwl/inquire-desktop`). **Never edit Inquire's folder from this project.**

- **Start menu** (`renderMenu` in `web/src/app.js`): eyebrow "NotePath", heading "Main Menu". A **Notes** console window (`.npn`): one row of four buttons, all the same size (Devon, Oct 2026): **My notes** · **My Tasks** (count of open tasks, red when some are overdue) · **one button labelled only "Coming soon"**, not linked to anything (`.slot.npn-soon`, `aria-disabled`) · **Note Office** on the far right; 2 × 2 under 1100 px, one column on phones. Under them **Recent**: the three most recently edited notes. (New note and Favourites were removed from the menu, Oct 2026.) Replace Coming soon when Devon names the feature it should hold.
- **My Tasks** (`web/src/tasks.js`, `window.NPTasks`; page `#tasks`, `renderTasksPage` in app.js, breadcrumb "Main Menu › My Tasks", Alt+T): the task list on the left (notes-list look: done circle, priority stripe + shape **High ▲ red `#E5675B` · Medium ◆ amber · Low ● cyan**, task picture, due date (Overdue in red, within 24 h in amber), ↻ repeat, ◷ reminders, ⌖ place, file count; search, By due date / By priority / Newest, ✓ Done shows or hides finished tasks, "n open · n overdue"), the overview on the right, all editable: **task picture** (click or drop a photo; "a picture of something in your life"), name, done, priority, **When** (date, optional time, Clear; Doesn't repeat / Every day / Every week: ticking a repeating task moves it to its next date and keeps it open), **Reminders** (At the due time, 10 min, 1 h, 1 day before, plus custom minutes/hours/days; a first due date brings "at the due time"; without a time they count back from 9:00), **Place** (Check address → OpenStreetMap Nominatim via the main process (`dict:lookup`, host allowlisted) → pick one → locked with its coordinates on a small tile map (OSM tiles, pin, ＋/−, credit; main.js sends Referer + User-Agent to tile.openstreetmap.org as OSM asks), Apple Maps / Google Maps links, Change unlocks), **Notes**, **Files, photos & videos** (choose, drop or paste; photos/videos in a gallery that opens large, other files listed and saved on click; any file ≤ 500 MB, in the notes' IndexedDB store via `InquireNotes.putImage/putFile`), **⤓ Calendar** (.ics with time, place, repeat, reminders: the baseline before Google/Apple sync), Delete with Undo. Store `notepath.tasks._local`. **Reminders**: tasks.js sends every reminder still to come to the main process (`inquireDesktop.tasks.schedule` → `tasks:schedule`), which shows a system notification at the time (even with the window closed; macOS keeps the app running) and tells the page (`tasks:fired` → a message with Open); a click opens the task. One missed in the last 6 h still shows once; shown ones are remembered (`notepath.tasks.fired`). Without the bridge the page checks every 20 s itself. Backups include tasks and their pictures/files (≤ 25 MB each).
- **My notes** is a **page** (`#notes`, `renderNotesPage` → `renderNotes`), not a window over the menu: no fog, breadcrumb "Main Menu › My notes", **‹ Back** first in the header (`.np-back`, also on My Tasks and Note Office: `modalWin(id, { back: true })` shows ‹ Back instead of ✕; Note Office has no ✕, Devon Oct 2026), the brand / Main Menu crumb / Alt+M / Alt+⌫ go back, Esc opens Settings as on the menu. `NPAGE.show(o)` switches folder or note in place. Header: "?" tips, **↶ Undo / ↷ Redo** (also ⌘Z / Ctrl+Z, ⇧⌘Z / Ctrl+Y outside text fields; `InquireNotes.undo/redo/history`: every write to the notes or folders store is a step, writes within 700 ms are one step, whole-store snapshots for the session; media of deleted notes stay until the app closes so undo can restore them) and a bright **＋ New Note** button (theme accent `var(--frame)`, `.np-newb`) that opens the title dialog (`askText` with `kinds`: **Standard note**, **Code note** (starts with a code box), **Music chart** (starts with a blank 16-bar lead sheet); the dialog keeps its fog and milky glass look) and files the note in the folder being viewed. Folders column · notes list · editor; the note bar has ☆ and Photo / Photo link / **▶ Video** / **Export…** / Delete (no folder picker or "Saved" text). Folders can be **starred** (☆ on the row, `fav` in the folder store, `setFolderFav`): starred folders sort first among their siblings, so starred top-level folders lead the column. The folders column lists each folder's notes under its subfolders; every folder has ▾/▸ to fold them (store `notefold`); both columns resize by dragging the line after them (`.nb-rzf` → `nbfw`, `.nb-rz` → `nbw`; double-click resets). **Drag a note** (from the list or the folders side bar) into the open note → a link titled with the note's name at the drop point (`api.insertNoteLink`); click it to open the note; **right-click it** (textmenu.js `linkMenu`) → Open · **Open in a new note tab** (side by side, `api.openSide` → `openFromLink`) · Remove link (keeps the words); onto the **⧉** spot that lights up at the right of the title → it opens **side by side** (`.nb-pane.p2`, `NOTES.split`), with Open as main, ▁ minimise (becomes a tab above the editor, `.nb-tabs`) and ⤢ maximise. Everything from Inquire 1.19: nested folders with drag and drop, Favourites, Unfiled, My order (drag, Alt+↑/↓) or Recently edited, ★ first, search, fold tabs and a resizable list, Delete with Undo, Save as .md, photos (file, paste, drop, link), note-to-note links.
- **My notes tabs** (Devon, Oct 2026): thumb tabs on the right edge of the My notes window (`.np-thumbs` in `renderNotesPage`; a row above it at phone width): **Notes** (everything above), **Code** and **Music** (coming soon, not built). Only the tabs are coloured: Notes NotePath amber-orange `#F2B84B`, Code blue `#4FA3F7`, Music magenta `#D97AE6`, changeable in Settings → Appearance → My notes tabs (`S.tabs` → `--tab-notes/-code/-music`). The open tab is remembered (`notepath.nspace`); routes `#notes` / `#code`; breadcrumb "Main Menu › My notes › Code".
- **Code tab** (`web/src/code.js`, `window.NPCode`; `renderNotes(m, focusBody, "code")` in app.js reuses the whole My notes machinery): a code file is a note with `space: "code"` and `code: { lang, src, stdin }` (html empty, body = source); code folders carry `space: "code"`. `InquireNotes.list()` / `folders()` with no space are the Notes tab only, so the menu, Recent, Note Office and pickers never see code; `InquireNotes.scope("code")` is the store seen from the Code tab. Same side bars (own folders, ★, My order, search, resize/fold), same side by side (⧉, ▁, ⤢) and drag and drop, Undo/Redo. **＋ New File** asks the language (cards: Python, C, C++, JavaScript, Java; "Coming soon" lists the rest, also disabled in the language menu) and starts with a small program. The pane: ☆ · language · **▶ Run** (⌘/Ctrl+Enter) · **⇄ Translate** · Save file · Delete, the name with a language badge, the editor (**Monaco 0.52.2**, the VS Code editor, themed from the NotePath theme; a plain code box if it cannot load), an **Output / Input** panel (Input = stdin, saved with the file) and a VS Code-style status bar. **Running**: JavaScript runs on this computer in a Web Worker made from the source (no eval; `prompt()` reads Input; 10 s limit); Python/C/C++/Java go to the run service in **Settings → Code** (Judge0 CE public server by default, Judge0 on RapidAPI with a key, or Piston), through the main process (`inquireDesktop.codeHttp` → `code:http`, HTTPS only). Judge0's language list is read once and the newest matching version is used. **AI** (⇄ Translate → a new file in the target language, opened side by side): the key lives only in the main process (`ai:status` / `ai:ask` in main.js; `NOTEPATH_AI_KEY` / `_PROVIDER` / `_MODEL` env, or `ai.config.json` beside main.js: copy `ai.config.example.json`; gitignored, packaged by `build.files`). Providers: `anthropic` (Messages API) or `openai`. Until it is set, Translate and Settings → Code say it is not set up.
- **Import & Export** (`web/src/io.js`, `window.NPIO`; Notes tab header **⇅ Import / Export**, and **Export…** on the note bar = This note): a window (`modalWin("io")`). **Export** This note / This folder (the folder being viewed, with its subfolders; Favourites, Unfiled) / Everything as **Markdown** (Obsidian: front matter, `[[links]]`, `- [ ]`, ``` fences, photos in `attachments/`), **Word .docx** (hand-written WordprocessingML: Title, Heading 2, bullets/numbers via numbering.xml, ☐/☒ checklists, Quote, Code, colours/sizes/fonts, photos), **Evernote / Apple Notes .enex** (ENML, `<en-todo>`, photos as resources by md5; one .enex per folder), **web page .html** (photos inside), **PDF** (main.js `export:pdf` prints the page in a hidden window; the browser preview opens Print) and **plain text**. One note → one file; several → a .zip that keeps the folders. **Import** files, a .zip or a whole folder (pick or drop; Obsidian vault): .md/.markdown (front matter dates, `[[links]]` / `[x](Other.md)` resolved to note links after everything is in, `![[pic.png]]` and relative images stored as photos, nested lists inside their item, fences → code boxes), .txt, .html/.htm (Google Docs styles → bold/italic/colour, h1 → title, tables → lines, data: images, checkboxes), .docx (styles, numbering, ListBullet/ListNumber, ☐/☒, Code style → code box, tables, photos), .enex (notes, created/updated, photos by md5, en-todo → checklist; several notes → a folder named after the file), Google Keep Takeout .json (pinned → ★, first label → a folder, trashed left out), Notion exports (32-hex ids stripped). Folders are recreated under "Put them in". PDF, OneNote, .rtf/.pages/.doc and NotePath backups are listed as skipped with the reason. No libraries: own zip reader/writer (CompressionStream / DecompressionStream deflate-raw), md5. Media are read straight from IndexedDB (`InquireNotes.mediaBlob`): the desktop CSP refuses fetch() of blob:/data: URLs.
- **Code in the Notes tab**: under the notes folders a **Code** divider lists the Code folders and files (`codeSection` in renderNotes; ▾ folds it, ↗ opens the Code tab). Click a file → it opens in the Code tab. Drag it into a note → a code box with a copy of its code and its language (`api.insertWidgetAt`); onto a notes folder / Unfiled / Favourites → a new note there holding that code box. The original always stays in Code. The Code box widget now also knows C, C++ and Java.
- **Editor** (`mountEditor` in `notes.js`, toolbar in `notes-widgets.js`): bold, italic, underline, **strikethrough**, **heading**, **bulleted list, numbered list, checklist** (NotePath additions), a **font menu** (4 bundled fonts + 12 system fonts, `span[data-f]`), a **size menu** of numbers 8–72 (normal text is 15, `span[data-s="18"]`), **one spectrum colour picker** (spectrum + greys, hex code, Recent colours in `notepath.recentcolors`, Normal colour; `span[data-c="#rrggbb"]` with an inline colour the sanitiser writes). Old notes keep the s/n/l/xl sizes and house-palette colour keys. Emoji + symbols panel, **Code box** (highlighting, line numbers), **Music chart** (staff, keyboard, chords, playback), **𝄞 Sheet** = lead sheet (`notes-sheet.js`, `NPSheet`: bars four to a line, key signature, clef, time, tempo, chord symbols per bar spread evenly (D-7, BbΔ7, F#ø are fine; jazz symbols are converted only for playback), melody per bar in the Music chart notation, accidentals against the key and the bar, "too long" bars, ＋/− 4 bars, type the whole chart with "|", ▶ Play melody + soft chords; uses `InquireWidgets.kit`), **Graph** (`notes-graph.js`: click a grid to add points, drag to move, click to remove, or type "x, y"; the grid sizes itself to the points, − / + / Fit; side panel writes the equations: curve through all points (default), straight lines between points, best-fit line, best-fit parabola, with slope/vertex/intercepts/r²), **Video** (file, YouTube, Vimeo, https link).
- **Lists** (Devon, Oct 12 2026; `block()` in notes-widgets.js, list helpers in `mountEditor`): pressing a list button again never takes the list off. Bullets or checklist again (or Tab) indents the item under the one above (`api.indentItem`; the first item can't, a message says so; an unticked box under a ticked one is not crossed out); Shift+Tab moves it back out; numbers again do nothing; bullets in a checklist switch it to bullets. **Delete (Backspace) at the start of an item** is the way to take a bullet, number or checkbox off: a sub-item moves out one level first, a top-level item becomes a plain line (the list splits around it). Enter on an empty sub-item moves it out a level. The "Write…" hint (`is-empty`) also goes once a heading, list, photo, widget or link is in the note.
- **Toolbar order** (Devon, Oct 12 2026): B · I · U · **H** · S, then bullets / numbers / checklist, font, size, colour. **Font, size or colour with nothing selected** (an empty line, or between words): `caretStyle` in `api.format` puts a span holding a zero-width space at the caret, so what is typed next gets it; more picks add to the same span; the stand-in space is stripped on input; picking a normal size/colour/font at the end of a styled span starts a new span after it that keeps the other two styles.
- **Folder icons** in the folders side bar (`folderIcon` in renderNotes, `.nb-fold-ic`): a closed folder while folded (▸), an open folder while its notes show (▾). The row's ☆ ＋ ✎ ✕ take no width until the row is hovered or focused.
- **Checklists**: selecting text across ticked items shows a floating **Uncheck all (n)** button (`.np-ck`, in `mountEditor`) that unticks the ticked items the selection touches.
- Formatting goes through `api.format(kind, value)` in `notes.js` (execCommand with stand-ins, then `fontToSpan`; "Normal"/"Default" uses `lift()` to split the spans around the words). Chromium edits inline colours itself, so `syncColors()` keeps `data-c` in step.
- **Note Office** (`web/src/office.js`, `window.NoteOffice`; the critical feature, keep it right): Main Menu → Note Office opens a fogged window (`modalWin("office")`) with an animated stick-figure office from Devon's Stickman prototype (kept for reference in `docs/note-office-prototype/`; his poses, routines and timing are the prototype's: keep the charm and attitude). **Motion is the prototype's v2.3** (Astra, ported Oct 12, 2026; `Stickman-for-Astra.md` + `ARMS-UPDATE.md` there are the spec): head radius 20.7675 with exactly 5 px of visible neck (`finishPose`); each arm one connected 42 + 45 px chain with a real elbow (`shoulder`, `articulateArms`, resolved once per frame after blending, before props; `lGoal`/`rGoal` kept for interruption blends); heel-to-toe stroll on fixed footholds with a trailing forearm (`travel`, `softenContact`); underhand ball tosses with catches and a desk bounce (`ballPose`, `ballMotion`; the deleted-notes "trash" routine uses the same tosses, then lobs into the bin); cocked-elbow plane throw that releases from the hand (`planePose`, `planeMotion`); authored acting phrases for sing, desk beat, notice and wave (`actingPose`). Clicking him (`greet`): mid-song or mid-beat he greets then resumes; during a stroll, filing, ball, plane, bin or reading it waits until he's done. Rules (Devon, Oct 2026):
  - **Every note is exactly one sheet.** Unfiled notes: the first 75 (by creation) lie on the furniture: two desk piles and the two filing-cabinet tops (pile chosen by the note id, so each sheet keeps its place). From the 76th on, floor stacks of up to 100 each (front of the floor, either side of the desk, then in front of it, then rows further back).
  - **Every folder is one open box** on the left or right of the room (side chosen by its top folder's id; subfolders sit with their parent, label "↳"), with one upright sheet per note; boxes widen with their notes and stack up to 4–7 high along the side walls, then go to the front of the floor. When things no longer fit, the room widens (zooms out) instead of overlapping (`relayout`).
  - The room is 800 × 480 at its core and takes the window's shape (no letterboxing; at least 1040 wide). Colours come from the theme (`palette()` reads `--panel`, `--text`, `--muted`, `--line-2`, `--frame`…); settings.js fires `inquire:theme` and the office repaints.
  - On open, what changed since the last visit (`notepath.office.seen`) plays: new notes flutter down, new folders drop in, notes filed into a folder are carried to their box (up to 3 trips), deleted notes are crumpled into the bin. Then greeting (surprise, wave), then his routines (sing, stroll, desk beat, read, paper plane, stretch, paper ball).
  - Click a sheet → that note in My notes; a box → that folder; him → he waves. Hover shows the title. Header: status line (his mood), counts, Pause.
  - Speed and memory: the room and every sheet are painted once into two cached bitmaps (behind him; the front floor strip in front of him) and repainted only when notes, folders, theme or size change; a frame is ~0.3 ms of drawing (60 fps with 3,000 notes in tests). ~30 fps when idle; nothing runs while closed (`destroy()` frees the bitmaps); Reduce motion = a still office. The window has no backdrop blur and, once open, the fogged app behind it is hidden (`body.office-on`): a blurred page under an animating canvas cost ~70 ms a frame.
- **Right-click** on selected words in a note (`textmenu.js`): Copy · **Define · Dictionary** (Wiktionary → Wikipedia → dictionaryapi.dev, shown in the menu; ＋ Save to note puts it under the line) · **Link to a note** · **Translate…** (a box right under the menu: Spanish / German / French via MyMemory `api.mymemory.translated.net`, free, no key, English source, ≤ 480 characters; Copy / Replace / ＋ Insert below; host allowed in main.js `DICT_HOSTS` and the CSP). Inquire's Glossary item is gone (NotePath has no glossary).
- **Not carried over (Devon's choice, Oct 2026)**: sign-in screen and accounts (NotePath opens straight to the start menu; one set of notes per computer), the Assist dock / floating Notes box, and everything about subjects, lessons, labs, glossary and achievements. Notes no longer link to subjects/fields/lessons.
- **System tray** (Devon, Oct 2026; main.js): on Windows and Linux, closing the window hides NotePath to the notification area so My Tasks reminders still arrive (one notification explains it the first time); the tray menu has Open NotePath, My Tasks, the next reminder, Quit NotePath. Settings → Usage: **Keep running in the system tray** (Windows/Linux) and **Start NotePath when I sign in** (Windows: starts hidden in the tray with `--hidden`; macOS: opens normally). Stored in `prefs.json` in the userData folder (main process). One NotePath at a time (`requestSingleInstanceLock`: opening it again shows the window). macOS keeps its usual Dock behaviour.
- **Settings** (Esc or the top-bar Settings button): Appearance (Inquire's 12 themes, Your colours + 3 presets, note link colour, My notes tab colours), Display & comfort (text size, interface size, reduce motion), Shortcuts (rebindable: Esc Settings, Alt+M menu, Alt+N My notes, Alt+Shift+N new note / new file in Code / new task in My Tasks, Alt+F favourites, Alt+T My Tasks, Alt+⌫ back), Usage (invert scroll; system tray and start at sign-in in the desktop app), Code (run service, address, key, JavaScript here on/off, Test, AI status; `notepath.code`), Data & backups (code files and folders are in the backup too) (export/import one JSON file with notes, folders, photos, videos ≤ 25 MB and settings), About (updates, EULA, repo link).

## Commands
- `node tools/build-web.js`: builds `app/index.html` (desktop) and `dist-web/notepath.html` (browser preview). Fails on any syntax error.
- `node tools/unit.js` (~1 s): every script parses, identity is consistent, helper rules work, Note Office layout rules (one sheet per note, 75 on furniture, stacks ≤ 100, a box per folder, places stay put).

## Release (auto-update reaches every installed copy)
`npm run release -- patch "Short note"` (or `minor`, `major`, exact `X.Y.Z`). It refuses if GitHub has newer commits, runs `npm run check`, bumps the version, commits everything, pushes, tags and pushes the tag. Devon runs it in Terminal (the device shell has no GitHub credentials). The Release workflow runs the Check workflow first; if it fails, nothing is published. Builds take ~5 min. Then confirm the release lists `latest-mac.yml`, `latest.yml` and `latest-linux.yml` (if one platform's upload dropped, Actions → the run → **Re-run failed jobs**). Check status from the device shell: `curl -s https://api.github.com/repos/InquiringOwl/notepath-desktop/actions/runs?per_page=3`.
- **v0.1.0 released Oct 11, 2026** (repo created, all three platforms built). Before the first `npm run release` on a Mac, run `npm install` once in the folder.
- macOS: the app is ad-hoc signed, not notarised, so the first launch says Apple "could not verify" it. Fix once: System Settings → Privacy & Security → **Open Anyway**, or `xattr -dr com.apple.quarantine /Applications/NotePath.app`. Updates install themselves (`updater-mac.js` swaps the app from the release zip); if macOS blocks it, the banner says where the download is. Notarising needs an Apple Developer account; release.yml already uses the secrets `MAC_CERT_P12_BASE64`, `MAC_CERT_PASSWORD`, `APPLE_ID`, `APPLE_APP_SPECIFIC_PASSWORD`, `APPLE_TEAM_ID` once they exist.
