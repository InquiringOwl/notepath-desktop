# NotePath: working brief

Read this first in every session. Keep it short and current: update it in the same commit as any change it describes.

## What NotePath is
A desktop notes console (Electron) for every kind of note a person would reach for a notepad for: quick lines, lists and checklists, meeting notes, study notes, photos, video, code and music. It is **the note-taking system of Inquire, cloned into its own app** (Inquire: `~/Documents/codex-desktop`, repo `InquiringOwl/inquire-desktop`). **Never edit Inquire's folder from this project.**

- **Start menu** (`renderMenu` in `web/src/app.js`): eyebrow "NotePath", heading "Main Menu". A **Notes** console window (`.npn`): one row with **My notes** and, beside it, **three buttons labelled only "Coming soon"**, not linked to anything (`.slot.npn-soon`, `aria-disabled`); under them **Recent**: the three most recently edited notes. (New note and Favourites were removed from the menu, Oct 2026: new notes are made in My notes, favourites are a folder there.) Replace one when Devon names the feature it should hold.
- **My notes** is a **page** (`#notes`, `renderNotesPage` → `renderNotes`), not a window over the menu: no fog, breadcrumb "Main Menu › My notes", the brand / Main Menu crumb / Alt+M / Alt+⌫ go back, Esc opens Settings as on the menu. `NPAGE.show(o)` switches folder or note in place. Header: "?" tips, **↶ Undo / ↷ Redo** (also ⌘Z / Ctrl+Z, ⇧⌘Z / Ctrl+Y outside text fields; `InquireNotes.undo/redo/history`: every write to the notes or folders store is a step, writes within 700 ms are one step, whole-store snapshots for the session; media of deleted notes stay until the app closes so undo can restore them) and a bright **＋ New Note** button (theme accent `var(--frame)`, `.np-newb`) that opens the title dialog (`askText` with `kinds`: **Standard note**, **Code note** (starts with a code box), **Music chart** (starts with a blank 16-bar lead sheet); the dialog keeps its fog and milky glass look) and files the note in the folder being viewed. Folders column · notes list · editor; the note bar has ☆ and Photo / Photo link / **▶ Video** / Save as .md / Delete (no folder picker or "Saved" text). Folders can be **starred** (☆ on the row, `fav` in the folder store, `setFolderFav`): starred folders sort first among their siblings, so starred top-level folders lead the column. The folders column lists each folder's notes under its subfolders; every folder has ▾/▸ to fold them (store `notefold`); both columns resize by dragging the line after them (`.nb-rzf` → `nbfw`, `.nb-rz` → `nbw`; double-click resets). **Drag a note** (from the list or a folder) into the open note → a link to it at the drop point (`api.insertNoteLink`); onto the **⧉** spot that lights up at the right of the title → it opens **side by side** (`.nb-pane.p2`, `NOTES.split`), with Open as main, ▁ minimise (becomes a tab above the editor, `.nb-tabs`) and ⤢ maximise. Everything from Inquire 1.19: nested folders with drag and drop, Favourites, Unfiled, My order (drag, Alt+↑/↓) or Recently edited, ★ first, search, fold tabs and a resizable list, Delete with Undo, Save as .md, photos (file, paste, drop, link), note-to-note links.
- **Editor** (`mountEditor` in `notes.js`, toolbar in `notes-widgets.js`): bold, italic, underline, **strikethrough**, **heading**, **bulleted list, numbered list, checklist** (NotePath additions), a **font menu** (4 bundled fonts + 12 system fonts, `span[data-f]`), a **size menu** of numbers 8–72 (normal text is 15, `span[data-s="18"]`), **one spectrum colour picker** (spectrum + greys, hex code, Recent colours in `notepath.recentcolors`, Normal colour; `span[data-c="#rrggbb"]` with an inline colour the sanitiser writes). Old notes keep the s/n/l/xl sizes and house-palette colour keys. Emoji + symbols panel, **Code box** (highlighting, line numbers), **Music chart** (staff, keyboard, chords, playback), **𝄞 Sheet** = lead sheet (`notes-sheet.js`, `NPSheet`: bars four to a line, key signature, clef, time, tempo, chord symbols per bar spread evenly (D-7, BbΔ7, F#ø are fine; jazz symbols are converted only for playback), melody per bar in the Music chart notation, accidentals against the key and the bar, "too long" bars, ＋/− 4 bars, type the whole chart with "|", ▶ Play melody + soft chords; uses `InquireWidgets.kit`), **Graph** (`notes-graph.js`: click a grid to add points, drag to move, click to remove, or type "x, y"; the grid sizes itself to the points, − / + / Fit; side panel writes the equations: curve through all points (default), straight lines between points, best-fit line, best-fit parabola, with slope/vertex/intercepts/r²), **Video** (file, YouTube, Vimeo, https link).
- **Checklists**: selecting text across ticked items shows a floating **Uncheck all (n)** button (`.np-ck`, in `mountEditor`) that unticks the ticked items the selection touches.
- Formatting goes through `api.format(kind, value)` in `notes.js` (execCommand with stand-ins, then `fontToSpan`; "Normal"/"Default" uses `lift()` to split the spans around the words). Chromium edits inline colours itself, so `syncColors()` keeps `data-c` in step.
- **Right-click** on selected words in a note (`textmenu.js`): Copy · **Define · Dictionary** (Wiktionary → Wikipedia → dictionaryapi.dev, shown in the menu; ＋ Save to note puts it under the line) · **Link to a note** · **Translate…** (a box right under the menu: Spanish / German / French via MyMemory `api.mymemory.translated.net`, free, no key, English source, ≤ 480 characters; Copy / Replace / ＋ Insert below; host allowed in main.js `DICT_HOSTS` and the CSP). Inquire's Glossary item is gone (NotePath has no glossary).
- **Not carried over (Devon's choice, Oct 2026)**: sign-in screen and accounts (NotePath opens straight to the start menu; one set of notes per computer), the Assist dock / floating Notes box, and everything about subjects, lessons, labs, glossary and achievements. Notes no longer link to subjects/fields/lessons.
- **Settings** (Esc or the top-bar Settings button): Appearance (Inquire's 12 themes, Your colours + 3 presets, note link colour), Display & comfort (text size, interface size, reduce motion), Shortcuts (rebindable: Esc Settings, Alt+M menu, Alt+N My notes, Alt+Shift+N new note, Alt+F favourites, Alt+⌫ back), Usage (invert scroll), Data & backups (export/import one JSON file with notes, folders, photos, videos ≤ 25 MB and settings), About (updates, EULA, repo link).

## Look (same as Inquire; follow it unless Devon says otherwise)
- EVE Online-inspired console: dark glass windows (`.win`: `--win-1/-2` gradient, thin `--line` border, bright corner tick top-left and a fainter one bottom-right), header strips (`.win-h`: small uppercase Saira label, letter-spaced, glowing square dot), slots (`.slot`) for big menu buttons.
- Palette: amber `#F2B84B`, cyan `#5CC8E0`, pink `#F07CA0`, violet `#B49BFF`, green `#7BD88F`; magenta `#D97AE6`, lime `#B5D65A`, red `#E5675B`. **UI chrome uses `var(--frame)`** (the theme's accent), never a fixed colour; amber is for stars/favourites, green for done/ticked, red for delete/warnings.
- Fonts bundled in `app/fonts`: STIX Two Text (headlines, note titles), IBM Plex Sans (body), IBM Plex Mono (counts, code), Saira Semi Condensed (uppercase labels). Noto Sans Symbols subset for alchemical symbols.
- Symmetry: boxes side by side share top and bottom edges; an incomplete row is centred; check at 1440, ~1000 and 400 px. Motion is a soft fade/blur (`vt-in`), always off under Reduce motion.
- Logo: a placeholder drawn by `tools/art/make-icon.py` (a console note page with a lit path of dots): `build/icon.png` (1024, electron-builder makes icns/ico), `app/brand/np-mark-64.png` (top bar, inlined by build-web). The wordmark is the text "NOTEPATH" in the top bar. Replace both when Devon supplies a logo.

## Identity (separate from Inquire and Inquire Law, so the apps never collide)
- Product **NotePath**, `appId com.wolfiescoven.notepath`, npm name `notepath-desktop`, version started at **0.1.0**, scheme `notepath://` (CSP in build-web.js), localStorage keys `notepath.*` (`notepath.notes._local`, `notepath.notefolders._local`, `notepath.settings`, `notepath.nbw` …), photos/videos in IndexedDB `notepath-notes`, userData folder "NotePath". Installer names `NotePath-…`.
- Repo and update source: **public `InquiringOwl/notepath-desktop`** (package.json `build.publish`, main.js `OWNER`/`RELEASES_REPO`, tools/release.js, Settings → About). `node tools/unit.js` fails if these drift apart.
- Internal code names stay Inquire's on purpose so fixes can be copied between the apps: preload bridge `window.inquireDesktop`, `InquireNotes`, `InquireWidgets`, `InquireSettings`, `InquireApp`, events `inquire:notes-changed`, `inquire:window`, `inquire:route`. They are never shown to users.

## Commands
- `node tools/build-web.js`: builds `app/index.html` (desktop) and `dist-web/notepath.html` (browser preview). Fails on any syntax error.
- `node tools/unit.js` (~1 s): every script parses, identity is consistent, helper rules work.
- `node tools/smoke.js` (~20 s): headless Chromium opens the start menu, My notes, Favourites, New note and every Settings tab at desktop and phone width; fails on any JS error/warning or sideways scroll.
- `node tools/interact.js` (~45 s): drives the features (118 checks): menu (My notes + Coming soon in one row, inert), new note kinds (code, lead sheet: chords, notes fill a bar, ＋4 bars, whole chart), folder ★, undo/redo (typing, star, new folder, ⌘Z), ▶ Video on the bar, Translate (mocked MyMemory), My notes page + ＋ New Note dialog, folder fold + notes in folders + folders resize, drag a note in (link) / onto ⧉ (side by side, minimise, maximise, close), folders/order drag and drop, ★ first, resize/fold, size/font/colour menus (+ Esc), headings, lists, checklists (tick + reload + Uncheck all), strikethrough, code, music, graph (points → equations, resize, fit, save), video, right-click Dictionary + Save + Link, delete + Undo, shortcuts, theme, backup export → import. **Add a check here for every new interactive feature.**
- `npm run check`: build + unit + smoke + interact. Run before every commit that touches `web/`.
- `npm start`: build and open the app locally (updates are only checked in installed copies).
- One-time setup on a new machine: `npm install && npx playwright install chromium`.
- The device shell (Cowork) can't download Playwright's Chromium: run smoke/interact in the cloud container (copy the folder, `npm i playwright@1.56.0` with `PLAYWRIGHT_SKIP_BROWSER_DOWNLOAD=1`, Chromium is preinstalled there) and bring changes back. Build and unit run fine on the device.
- The desktop top bar is an Electron drag strip (`-webkit-app-region:drag`) that Electron still honours under windows drawn over it, so anything over the top bar must be `no-drag` (style.css: overlays, popups and the bar itself while a window is open). That was the "✕ only clicks on its edges" bug.
- Popups that handle Esc themselves must be listed in settings.js's Esc check (`.tm-menu, .nk-pick, .nr-panel, .ask-ov, .nv-pop, .np-pop`) or Esc also closes My notes.
- Don't run `git status` (or other git commands) from the device shell: it can leave `.git/index.lock`, which that shell can't delete. Devon runs git in Terminal.

## Release (auto-update reaches every installed copy)
`npm run release -- patch "Short note"` (or `minor`, `major`, exact `X.Y.Z`). It refuses if GitHub has newer commits, runs `npm run check`, bumps the version, commits everything, pushes, tags and pushes the tag. Devon runs it in Terminal (the device shell has no GitHub credentials). The Release workflow runs the Check workflow first; if it fails, nothing is published. Builds take ~5 min. Then confirm the release lists `latest-mac.yml`, `latest.yml` and `latest-linux.yml` (if one platform's upload dropped, Actions → the run → **Re-run failed jobs**). Check status from the device shell: `curl -s https://api.github.com/repos/InquiringOwl/notepath-desktop/actions/runs?per_page=3`.
- **v0.1.0 released Oct 11, 2026** (repo created, all three platforms built). Before the first `npm run release` on a Mac, run `npm install` once in the folder.
- macOS: the app is ad-hoc signed, not notarised, so the first launch says Apple "could not verify" it. Fix once: System Settings → Privacy & Security → **Open Anyway**, or `xattr -dr com.apple.quarantine /Applications/NotePath.app`. Updates install themselves (`updater-mac.js` swaps the app from the release zip); if macOS blocks it, the banner says where the download is. Notarising needs an Apple Developer account; release.yml already uses the secrets `MAC_CERT_P12_BASE64`, `MAC_CERT_PASSWORD`, `APPLE_ID`, `APPLE_APP_SPECIFIC_PASSWORD`, `APPLE_TEAM_ID` once they exist.

## Bringing improvements over from Inquire
NotePath's notes engine is Inquire's, so a fix there usually fits here: compare `web/src/notes.js`, `notes-widgets.js`, `textmenu.js`, `settings.js` and the notes part of Inquire's `app.js` (`renderNotes`, `notesLayout`, `askText`, `modalWin`), copy the change, then replace `codex.`/`inqlaw.` storage prefixes with `notepath.` and drop anything about subjects, lessons, glossary, accounts or the Assist dock. `npm run check` must pass.
