# NotePath: working brief

Read this first in every session. Keep it short and current: update it in the same commit as any change it describes.

## What NotePath is
A desktop notes console (Electron) for every kind of note a person would reach for a notepad for: quick lines, lists and checklists, meeting notes, study notes, photos, video, code and music. It is **the note-taking system of Inquire, cloned into its own app** (Inquire: `~/Documents/codex-desktop`, repo `InquiringOwl/inquire-desktop`). **Never edit Inquire's folder from this project.**

- **Start menu** (`renderMenu` in `web/src/app.js`): eyebrow "NotePath", heading "Main Menu". A **Notes** console window (`.npn`): one row of five buttons, all the same size (Devon, Oct 12 2026, v0.5.2): **My notes** · **My Tasks** (count of open tasks, red when some are overdue) · **My Code** (`data-a="code"`, file count; opens the Code space of the notes page) · **My Music** (`.slot.npn-soon.npn-music`, "Coming soon", `aria-disabled`, not built) · **Note Office** on the far right. Above 1100 px the icon sits above the words; 3 + 2 (second row centred) under 1100 px, one column on phones. The glyphs of My notes / My Code / My Music take the colours in Settings → Appearance → **Main Menu colours** (`S.tabs` → `--tab-notes/-code/-music`, amber-orange / blue / magenta). Under them **Recent**: the three most recently edited notes.
- **My Tasks** (`web/src/tasks.js`, `window.NPTasks`; page `#tasks`, `renderTasksPage` in app.js, breadcrumb "Main Menu › My Tasks", Alt+T): the task list on the left (notes-list look: done circle, priority stripe + shape **High ▲ red `#E5675B` · Medium ◆ amber · Low ● cyan**, task picture, due date (Overdue in red, within 24 h in amber), ↻ repeat, ◷ reminders, ⌖ place, file count; search, By due date / By priority / Newest, ✓ Done shows or hides finished tasks, "n open · n overdue"), the overview on the right, all editable: **task picture** (click or drop a photo; "a picture of something in your life"), name, done, priority, **When** (date, optional time, Clear; Doesn't repeat / Every day / Every week: ticking a repeating task moves it to its next date and keeps it open), **Reminders** (At the due time, 10 min, 1 h, 1 day before, plus custom minutes/hours/days; a first due date brings "at the due time"; without a time they count back from 9:00), **Place** (Check address → OpenStreetMap Nominatim via the main process (`dict:lookup`, host allowlisted) → pick one → locked with its coordinates on a small tile map (OSM tiles, pin, ＋/−, credit; main.js sends Referer + User-Agent to tile.openstreetmap.org as OSM asks), Apple Maps / Google Maps links, Change unlocks), **Notes**, **Files, photos & videos** (choose, drop or paste; photos/videos in a gallery that opens large, other files listed and saved on click; any file ≤ 500 MB, in the notes' IndexedDB store via `InquireNotes.putImage/putFile`), **⤓ Calendar** (.ics with time, place, repeat, reminders: the baseline before Google/Apple sync), Delete with Undo. Store `notepath.tasks._local`. **Reminders**: tasks.js sends every reminder still to come to the main process (`inquireDesktop.tasks.schedule` → `tasks:schedule`), which shows a system notification at the time (even with the window closed; macOS keeps the app running) and tells the page (`tasks:fired` → a message with Open); a click opens the task. One missed in the last 6 h still shows once; shown ones are remembered (`notepath.tasks.fired`). Without the bridge the page checks every 20 s itself. Backups include tasks and their pictures/files (≤ 25 MB each).

Header: "?" tips, **↶ Undo / ↷ Redo** (also ⌘Z / Ctrl+Z, ⇧⌘Z / Ctrl+Y outside text fields; `InquireNotes.undo/redo/history`: every write to the notes or folders store is a step, writes within 700 ms are one step, whole-store snapshots for the session; media of deleted notes stay until the app closes so undo can restore them) and a bright **＋ New Note** button (theme accent `var(--frame)`, `.np-newb`) that opens the title dialog (`askText` with `kinds`: **Standard note**, **Code note** (starts with a code box), **Music chart** (starts with a blank 16-bar lead sheet); the dialog keeps its fog and milky glass look) and files the note in the folder being viewed. Folders can be **starred** (☆ on the row, `fav` in the folder store, `setFolderFav`): starred folders sort first among their siblings, so starred top-level folders lead the column. The folders column lists each folder's notes under its subfolders; every folder's icon folds them (store `notefold`; see Folders column below); both columns resize by dragging the line after them (`.nb-rzf` → `nbfw`, `.nb-rz` → `nbw`; double-click resets). **Drag a note** (from the list or the folders side bar) into the open note → a link titled with the note's name at the drop point (`api.insertNoteLink`; dropped inside a word it goes after the word, with a space either side); click it to open the note; **right-click it** (textmenu.js `linkMenu`) → Open · **Open in a new note tab** (side by side, `api.openSide` → `openFromLink`) · Remove link (keeps the words). **Drag a folder** in → a folder link (`a.nlink[data-folder]`, `api.insertFolderLink`, a small folder before its name) that opens that folder (`openFolderLink`; right-click: Open folder · Remove link; dragging it in never moves the folder). Drag a note onto the **⧉** spot that lights up at the right of the title → it opens **side by side** (`.nb-pane.p2`, `NOTES.split`), with Open as main, ▁ minimise (becomes a tab above the editor, `.nb-tabs`) and ⤢ maximise. Everything from Inquire 1.19: nested folders with drag and drop, Favourites, Unfiled, My order (drag, Alt+↑/↓) or Recently edited, ★ first, search, fold tabs and a resizable list, Delete with Undo, Save as .md, photos (file, paste, drop, link), note-to-note links.

  - **A✓ Grammar check**: **LanguageTool**'s free public service (Devon's choice; no key; `api.languagetool.org/v2/check`, the desktop app posts through main.js `grammar:check`, the browser build fetches it, host in the CSP). "This note is" sets how strict (`NPAssist.GTYPES`): **Quick note** (spelling and clear mistakes), **School & study** (default: + punctuation, capitals, mixed-up words), **Work & business** (+ style), **Creative writing** (style, repetition and capitals left alone), **Formal & academic** (level `picky`, every rule); language US / UK / Canada / Australia / detect. Kept per note in `notepath.grammar` (`{ def, lang, notes: { id: type } }`). Each problem shows the words, the reason and up to 4 suggestions: a click puts it straight into the note (`textMap` / `rangeAt` / `locate` map the plain text back to the editor's text nodes, skipping widgets; later matches shift with `shiftMatches`), Ignore drops it, a click on the words selects them in the note. Up to 18,000 characters per check (`GT_MAX`). The box says the words are sent to languagetool.org.
